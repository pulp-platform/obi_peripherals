# obi_uart 16550 Compatibility Notes

This file tracks the compatibility tests that should guard refactors of the UART
implementation. Linux 8250/16550 behavior is the tie breaker when the historical
16550 documentation is ambiguous.

The compatibility baseline is the TI TL16C550C programming model, with the
current Linux 8250 driver as the tie breaker where historical implementations
differ. The primary references and the current directed-test inventory are in
[`verification_matrix.md`](verification_matrix.md).

The implementation currently has directed coverage for register reset and
DLAB sharing, read-clear status and interrupt behavior, visible 16-byte RX FIFO
occupancy and trigger levels, exact 8N1 character timeout, THR write overlap,
THRE/TEMT timing, and one/two/1.5-stop TX paths. The matrix deliberately keeps
uncovered modes and unresolved optional features visible rather than treating
the 16550-compatible label as complete coverage.
